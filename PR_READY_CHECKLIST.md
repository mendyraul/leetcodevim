# Review checklist

- Review the existing pull-recovery/scaffold fixes alongside the companion.
- Run pytest, Ruff, package build, and scripts/smoke_wheel.py.
- Run headless Vim and Neovim tests with both editors available.
- Review docs/capabilities.md for native features and explicit browser fallbacks.
- Complete manual signed-in acceptance before claiming account features verified.
- Check hosted CI after publishing; local success does not establish GitHub CI status.

Work is on feat/terminal-companion. No public posting, registration, or official
submission is performed by the automated checks.
